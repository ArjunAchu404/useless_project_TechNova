# Excuse Bureau 🎯

## Basic Details

### Team Name: TechNova

### Team Members

- Member 2: Devika V D - Thejus Engineering College

### Project Description

Excuse Bureau is a fun AI-powered web application that generates creative,
ridiculous, and entertaining excuses for different situations.

Users can enter a situation and receive an AI-generated excuse along with
a believability score. They can also copy, shorten, improve, and revisit
previously generated excuses.

### The Problem (that doesn't exist)

Sometimes you need a perfect excuse, but your brain decides to stop
working exactly when you need it.

Whether you are late for work, forgot your homework, missed a meeting,
or need to escape an awkward situation, coming up with a creative excuse
can be surprisingly difficult.

### The Solution (that nobody asked for)

Introducing the Excuse Bureau — an unnecessarily advanced AI-powered
bureau dedicated to solving the world's most unnecessary excuse problems.

Just enter your situation and let the Bureau generate a ridiculous excuse
for you. You can make it shorter, improve it, copy it, or start over.

Because apparently, we needed AI for excuses.

### Implementation

For Software:

The application is implemented as a responsive single-page web application
using HTML, CSS, and JavaScript.

Users enter a situation into the input field. The application sends the
request to the Google Gemini API, which generates a short, creative, and
ridiculous excuse.

The generated excuse is displayed along with a believability score.

The application also provides features such as:

- AI-generated excuses
- Believability score
- Recent excuses history
- Copy excuse
- Shorten excuse
- Improve excuse
- Start over
- Situation categorization
- Responsive user interface

The application categorizes situations into:

- Work
- Homework
- Social
- General

### Implementation

For Software:

The application is built using HTML, CSS, and JavaScript and uses the
Google Gemini API to generate creative excuses based on user input.
